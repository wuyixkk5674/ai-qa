# 人工智能导论 · 课程资料

## 课程简介

本课程面向计算机相关专业本科生，系统介绍人工智能的基本概念、核心算法与工程实践。课程共 32 学时，其中理论 20 学时、实验 12 学时。考核方式为平时作业 20%、实验报告 30%、期末闭卷考试 50%。课程要求掌握 Python 基础语法，并能够使用 NumPy 完成基本的矩阵运算。

## 机器学习基础

机器学习研究如何让计算机从数据中自动获取规律，而不依赖人工编写的固定规则。一个典型的机器学习流程包括：数据收集、数据清洗、特征工程、模型训练、模型评估与部署上线。

按照训练数据是否带有标签，机器学习可分为监督学习、无监督学习和半监督学习。监督学习使用带标签的数据，典型任务有分类与回归；无监督学习使用无标签数据，典型任务有聚类与降维。

模型训练的本质是最小化损失函数。常用的优化方法是梯度下降，学习率过大会导致震荡甚至发散，学习率过小则收敛缓慢。为了防止过拟合，可以使用正则化、数据增强、早停和 Dropout 等手段。

## 监督学习与无监督学习

常见的监督学习算法包括线性回归、逻辑回归、决策树、支持向量机（SVM）、K 近邻（KNN）以及集成学习方法如随机森林和梯度提升树（GBDT）。

K 近邻算法通过计算样本之间的距离，取最近的 K 个邻居进行投票或平均，K 值过小容易受噪声影响，K 值过大则会导致欠拟合。SVM 的核心思想是在特征空间中寻找最大间隔超平面，并通过核函数处理线性不可分问题。

无监督学习的代表算法是 K 均值聚类（K-Means）和主成分分析（PCA）。K-Means 需要预先指定簇的数量 K，对初始中心敏感，通常需要多次随机初始化。PCA 通过线性变换把高维数据投影到低维空间，保留方差最大的方向，常用于降维与可视化。

## 神经网络与深度学习

人工神经网络由输入层、隐藏层和输出层组成，每个神经元对输入做加权求和后经过激活函数输出。常用的激活函数有 ReLU、Sigmoid 和 Tanh，其中 ReLU 计算简单且能缓解梯度消失问题。

神经网络的训练依靠反向传播算法：前向传播计算预测值，损失函数计算误差，反向传播利用链式法则计算各层参数的梯度，再由优化器更新参数。常见的优化器有 SGD、Momentum、Adam。

深度学习在计算机视觉和自然语言处理领域取得了显著成果。卷积神经网络（CNN）通过卷积核提取局部特征，适合处理图像；循环神经网络（RNN）及其变体 LSTM 适合处理序列数据。Transformer 基于自注意力机制，可以并行处理序列，是当前大语言模型的基础架构。

## 大语言模型

大语言模型（LLM）通常基于 Transformer 架构，在海量文本上通过预测下一个词的方式进行预训练，再经过指令微调与人类反馈强化学习（RLHF）对齐。

大语言模型存在幻觉问题，即生成看似合理但实际错误的内容。在课程答疑等场景中，常用检索增强生成（RAG）来缓解幻觉：先从知识库中检索与问题相关的资料，再把资料作为上下文交给模型，要求模型依据资料作答并给出出处。

调用大语言模型的常见方式是兼容 OpenAI 协议的 HTTP 接口，请求路径通常为 /chat/completions，需要提供 API Key、基础地址和模型名称。工程上必须设置超时时间，并对网络错误、非 200 响应和空内容做好兜底处理。

## 模型评估指标

分类任务常用准确率（Accuracy）、精确率（Precision）、召回率（Recall）和 F1 值评估。准确率是预测正确的样本占全部样本的比例；精确率衡量预测为正的样本中真正为正的比例；召回率衡量真实为正的样本中被找出来的比例；F1 值是精确率与召回率的调和平均。

当数据类别不平衡时，准确率会产生误导，此时应优先关注 F1 值或 AUC。回归任务常用均方误差（MSE）、均方根误差（RMSE）和平均绝对误差（MAE）。

评估时要注意划分训练集、验证集和测试集，测试集只能用于最终评估，不能参与调参，否则会造成数据泄漏。
